# Personal preferences

## Interaction

- Less is more: prefer terse replies
- Prefer explaining the intention over walking through code unless it makes sense
- Do not use em dashes

## Scripts

- Bash is fine for simple operations, but not for reproducible scripts
- Reproducible scripts should be written in erasable TypeScript syntax (only type syntax that strips cleanly; no enums/namespaces/parameter properties) and in a `.mts` file.
